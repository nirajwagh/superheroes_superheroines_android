# Superheroes & Superheroines

An Android app to explore **superheroes and superheroines** with character details, images, and related videos.

Built using the **Marvel API**, **YouTube Data API v3**, and **android-youtube-player** library.

## Features

* Browse superheroes & superheroines
* Character information and details
* Character images
* Related YouTube videos
* Smooth and minimal UI

## Tech Stack

* **Marvel API** – character information and images
* **YouTube Data API v3** – related character videos
* **android-youtube-player** – in-app YouTube playback
* **ViewPager2** – character image carousel
* **Volley** – API requests
* **Glide** – image loading
* **Lottie** – animations

## Important Note

The original **Marvel Developer API** has been sunset. Because of this, some online functionality may no longer work as originally intended.

This repository is preserved as a portfolio and learning project.

## API Keys

To run the project fully:

* Add your **Marvel Public & Private API Keys**
* Add your **YouTube Data API v3 Key**
